# Getting Started with SOC Analysis

## What is a SOC?

A Security Operations Center (SOC) is a centralized team that monitors, detects, analyzes, and responds to cybersecurity incidents. Think of it as the digital security command center for an organization.

## Key SOC Roles

### Tier 1 - Security Analyst
- Monitor security alerts
- Triage incoming incidents
- Escalate complex cases

### Tier 2 - Incident Responder
- Investigate escalated incidents
- Perform deeper analysis
- Contain and remediate threats

### Tier 3 - Threat Hunter
- Proactively search for threats
- Develop detection rules
- Research new attack techniques

## Essential Tools

Every SOC analyst should be familiar with:

1. **SIEM (Security Information and Event Management)**
   - Wazuh (Open Source)
   - Splunk
   - Elastic Stack

2. **IDS/IPS (Intrusion Detection/Prevention)**
   - Suricata
   - Snort

3. **Network Analysis**
   - Wireshark
   - tcpdump

## Getting Started

If you're new to SOC analysis, here's a learning path:

1. Learn networking fundamentals (TCP/IP, OSI model)
2. Understand common attack vectors
3. Set up a home lab with Wazuh
4. Practice log analysis
5. Learn basic scripting (Python, Bash)
